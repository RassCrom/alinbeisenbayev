## Use the styles on your own map

Each `.qml` file matches a layer of a [Geofabrik](https://download.geofabrik.de/) GeoPackage: `landuse`, `water`, `roads`, `places`, `pois` and so on. In QGIS, open Layer Properties, then Style, then Load Style, and pick the file with the same name.

Keep this layer order, top to bottom:

1. `pois`, `pois_a`, `transport`, `transport_a`: the icons
2. `places`: the place names
3. `relief_light` and `relief_shadow`: one hillshade, drawn twice in screen and multiply blend
4. `transit`: a second copy of `railways`, GTA VI only
5. `roads`, `railways`, `buildings`, `ferry`, `waterways`, `water`, `natural_a`, `landuse`
6. `coast` and `sea`

Then set the project background colour to the style's land colour, in Project, Properties, General.

## How the sea works

The sea is one raster: each pixel holds its distance from the coast. A single colour ramp in `sea.qml` turns that distance into colour, light by the shore and deep blue offshore. The stops are in each palette above.

Icons are placed through the label engine, not the symbology, so QGIS thins them and keeps them off the place names. You edit them in the Labels tab.
